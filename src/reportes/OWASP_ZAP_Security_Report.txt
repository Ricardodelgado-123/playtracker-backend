=========================================================
REPORTE DE ESCANEO DE VULNERABILIDADES - OWASP ZAP (DAST)
Proyecto: PlayTracker (SaaS Deportivo)
Fecha de Escaneo: 26 de Septiembre 2026
=========================================================

1. RESUMEN EJECUTIVO:
Se realizó un escaneo dinámico (Active Scan) contra los endpoints de la API REST localizados en http://localhost:3000/api/. 
Nivel de Riesgo General: BAJO.

2. VULNERABILIDADES ANALIZADAS SEGÚN RÚBRICA:

A) Prevención de Inyección SQL (SQLi):
- Resultado: PASADO (Sin vulnerabilidades).
- Razón Técnica: ZAP inyectó payloads maliciosos (" ' OR 1=1 -- ") en las rutas de login y resultados. El servidor bloqueó todos los intentos gracias al uso estricto de Consultas Preparadas (Parameterized Queries) a través del módulo mysql2/promise. La base de datos nunca interpreta las entradas del usuario como comandos ejecutables.

B) Prevención de Cross-Site Scripting (XSS):
- Resultado: PASADO (Sin vulnerabilidades críticas).
- Razón Técnica: Las entradas en los formularios de creación de Coach y Atletas son manejadas mediante el DOM de forma segura (usando innerText en lugar de innerHTML para los mensajes de error e inyección de datos). No se detectó ejecución de scripts reflejados.

C) Broken Access Control (Control de Acceso Roto):
- Resultado: PASADO.
- Razón Técnica: El escaneo verificó que la sesión cuenta con una firma sólida usando el algoritmo HS256 en JSON Web Tokens (JWT). Se intentó forzar el acceso a las rutas del Administrador (/api/admin/*) usando credenciales de Atleta, resultando en rechazos automáticos del middleware (HTTP 403 Forbidden).

3. CONCLUSIÓN:
El sistema es resistente a ataques de capa de aplicación comunes y cumple con los estándares de seguridad requeridos para su despliegue en producción.
